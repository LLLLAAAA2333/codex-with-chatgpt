# Codex with ChatGPT 安装说明

这份技能让 ChatGPT 参与方案讨论和代码审查，由 Codex 实现和测试。分享包包含截至 2026 年 10 月 11 日的本地源码，以及自动创建、验证和绑定目标对话的最新规则。

当前主要支持 macOS。需要 Codex、Node.js 20 或以上版本，以及项目指定的 pnpm 11.24.0。在线连接还需要 cloudflared、可用的 ChatGPT 账号和添加自定义连接器的权限；本地安装不需要这些在线配置。Windows 和 Linux 尚未在这个分享包中验证。

## 让 Codex 帮你安装

1. 解压，把整个 `codex-with-chatgpt` 文件夹放到准备长期保留的位置。安装后的技能会引用它，不要装完就删除或移动。
2. 用 Codex 打开这个文件夹，把下面这段话发给它：

> 请阅读这个文件夹里的安装说明，安装 codex-with-chatgpt。我授权安装缺少的 Node.js、项目指定版本的 pnpm 和项目依赖，构建并测试项目，运行 scripts/install-skill.mjs 安装技能。不要覆盖已有技能；如果已存在，请先检查并保留旧版本。先完成本地安装，不启动公网隧道，不创建 OAuth 授权，也不修改其他 Codex 配置。

安装脚本会复制完整的 `skill/`，包括 `references/`，并自动写入你电脑上的项目路径。默认位置是 `~/.codex/skills/codex-with-chatgpt`；如果设置了非空 `CODEX_HOME`，则使用该目录下的 `skills/codex-with-chatgpt`。

## 自己在终端安装

确认 Node.js 和项目指定的 pnpm 已准备好，在解压后的项目目录逐条运行。任何一步失败，都先解决错误再继续。

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm run typecheck
pnpm run build
pnpm test
node scripts/install-skill.mjs
node bin/c2c.js --help
```

最后一个命令只显示帮助，不会启动桥接或隧道。安装脚本遇到已有同名技能会停止，不会覆盖；请先备份并移走旧目录，再重试。移动整个项目后，需要重新安装技能来更新路径。

## 开始使用

在 Codex 中打开你真正要开发的项目，开始一个新对话并发送：

> 使用 codex-with-chatgpt，帮我和 ChatGPT 协作处理当前项目。先检查现有连接，复用有效授权和已绑定对话；没有绑定时，自动创建并验证专用对话，再保存绑定。

新规则会优先复用工作区的有效绑定，即使换了 Codex 对话也一样。已有 ChatGPT Project 绑定时，在该 Project 中创建缺失的对话；没有 Project 绑定时，创建普通专用对话，不要求你先提供链接。核对工作区身份通过后才会保存绑定。

你使用自己的账号完成登录、验证码和必要的 OAuth 授权，完成后 Codex 会继续。新建对话不会自动触发重新授权；超时也不会被当成授权失效。首次公网连接或新增软件安装仍会说明所需操作，并按你已给出的权限处理。

如果当前 Codex 环境没有可用的浏览器工具，或者账号不能添加连接器，可以继续使用 README.zh-CN.md 中的本地交接方式。技能规则已经更新，浏览器自动化仍取决于你实际使用的环境。

## 分享包包含什么

包含源码、测试、锁文件、技能及其引用文档、安装脚本和项目说明。未包含依赖目录、构建缓存、Git 历史、环境变量文件、账号凭据、浏览器数据、Cloudflare 配置或个人会话与执行记录。

测试中的 Project 标识和示例工作区名称已换成虚构值；安全测试里出现的私钥头和令牌样例是测试文本。`SHA256SUMS.txt` 可用于核对包内文件有没有被改动，不是发布者的数字签名。

这份包来自本地工作区快照，不代表 GitHub 上已发布了相同版本。构建与自动化测试的检查结果见 `打包检查.txt`。没有执行真实账号登录、OAuth 或公网浏览器端到端验证。
